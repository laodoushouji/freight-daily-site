Maersk欧线No SI No Load政策2026年11月生效：货代操作对策

2026年11月20日

⚡ 对货代的影响（30秒看懂）

⚡ 对货代的影响（30秒看懂）： 1. 11月17日起 Maersk 欧线执行 No SI, No Load：SI 提交不完整或迟交，柜子直接甩船，你的船期顺延一周起步。 2. 欧线即期价 $2,700/40HQ 持平，但甩货后改配下一班，舱位紧张时可能被迫接受 higher 水位价，实际成本多 $100-300/40HQ。 3. 若因 SI 问题产生 re-work（改单、重新申报），马士基按常规收取改单费 EUR 50-100/票，且 VGM/AMS 补报还可能被目的港罚金。 4. 客户端：到港延误 5-7 天，收货人若按 L/C 交货期索赔，风险在你这里。

💡 操作建议

💡 操作建议： 1. 11月21日前，把所有 Maersk 欧线订舱的 SI 提交截止时间（SI cut-off）核对一遍，提前 24-48 小时完成 SI，别踩 deadline。 2. 交给团队一条硬规则：品名、件毛体、收发货人、HS Code 四要素不全的托书，一律退回客户，不接单不上船。 3. 已经上船但 SI 有瑕疵的，立刻联系 Maersk 客服做补救，优先走在线自助补录，避免滞留港口甩船。
11月17日起，Maersk 在欧洲航线正式执行 No Shipping Instruction, No Load（无 SI 不装船）政策。这不是运价调整，而是操作纪律收紧——但对货代来说，实际后果可能比涨 $200 更疼。 先看市场背景。本周欧线即期价 $2,700/40HQ，与前一周持平。上海、宁波等泊 2-5 天，鹿特丹 1-2 天，整条链路运行正常，没有拥堵 leverage 推高运价。也就是说，这次政策出台不是市场逼的，是船司主动做的流程管控——Maersk 想减少因 SI 错漏导致的 re-working、改单和目的港纠纷。 对你意味着什么？三笔账要算清楚： 第一笔：甩船成本。政策字面意思很直接——SI 没按时提交或信息不全，柜子不装船。你以为货上了车就安全了，实际最危险的窗口是 SI cut-off 到 actual loading 之间。一旦甩船，改配下一班通常等 5-7 天，赶上舱位紧还得加价，$100-300/40HQ 的差价很可能落到你头上。 第二笔：改单成本。SI 提交后发现品名或毛重错误要改，常规改单费 EUR 50-100/票。如果涉及 AMS/ENS 补报，目的港还可能收罚金。一个月出 30 票欧线，只要 3 票踩雷，改单费就吃掉大几百欧。 第三笔：客户信任成本。这最隐性也最贵。收货人因到港延误 5-7 天向发货人索赔，发货人转头找你——而 SI 是谁交的？如果是你自己操作失误，责任躲不掉。 怎么应对？ 1. 今天就把 Maersk 欧线的 SI cut-off 时间在团队内公示。多数船司欧线 SI cut-off 是 ETD 前 72 小时，但各港口不同，别靠记忆操作。 2. 设一道内部审核关：托书四要素（品名、件毛体、收发货人、HS Code）不全就不放舱。宁可晚半天接单，不要赌 SI 能蒙混过关。 3. 对长期客户，把 No SI No Load 政策写进订舱确认函，让客户知道迟交托书的后果由谁承担。 4. 已经发生 SI 问题、柜子还在堆场的，今明两天内联系 Maersk 补救，走在线自助系统比打电话快。 一句话总结：政策本身不收你一分钱，但它把你操作流程的每一处马虎都变成了真金白银的损失。欧线运价没涨，风险却在涨——管好 SI，就是管住利润。
