UAE海运舱单预申报新规9月23日实施：中东线货代操作指南（2026）

2026年09月28日

⚡ 对货代的影响（30秒看懂）

⚡ Maersk 9月23日起实施 UAE 预报舱单（Advance Cargo Manifest）新规操作指引，走阿联酋（杰贝阿里Jebel Ali为主）的货，舱单信息必须在开船前提交，漏报或晚报的柜子可能被拒绝装船或在杰贝阿里海关卡关。中东线客户面临 1-3 天的清关延误风险，产生的堆存费（杰贝阿里约 $30-60/天/柜）将由发货方承担。

💡 操作建议

💡 1) 立即核对手上所有 UAE 目的港在途/待发订单的舱单数据（收发货人全称、HS Code、货物明细）是否完整，缺失项 48小时内补齐给订舱代理；2) 9月23日后的 UAE 舱位，要求订舱代理书面确认舱单截单时间（通常为 ETD 前 24-48 小时），写进内部 SOP；3) 经杰贝阿里中转去往其他海湾港口（达曼、科威特）的货同样受此新规约束，不要只盯目的港是迪拜的柜子。
9月28日的采集数据里，Maersk 有一条容易被标题误导的通知：系统把它归类为"欧线附加费"，但公告正文实际是《UAE Advance Cargo Manifest Implementation - Operational Guidelines》，即阿联酋预报舱单新规的操作指引，生效日期 2026年9月23日。这是一条合规类变化，不是涨价，但对中东线操作的冲击可能比一次小幅度涨价更大。 先解释什么是预报舱单。传统流程下，舱单（Manifest）可以在开船后一段时间内补交；而 Advance Cargo Manifest 要求承运人在船舶抵达阿联酋港口之前，就把完整舱单数据提交给海关系统，部分口岸要求 ETD 前 24-48 小时完成。舱单数据不全、HS Code 与实际货物不符、收发货人信息不完整的柜子，会被拒绝装船，或到了杰贝阿里后无法卸船放行。 对货代意味着三件事。 第一，单证提前期被压缩。以前可以"先订舱后补料"的操作习惯必须改掉：委托书（SI）的截止时间实际上提前了。走 UAE 的货，发货人的装箱单、发票、HS Code 必须在订舱时就齐备，不能再等截关日才收齐。9月23日之后发的柜子，任何一项数据缺失都会直接反应在船司的系统里。 第二，中转货是重灾区。很多同行以为这条新规只管目的港是迪拜的货，错了——经杰贝阿里中转去达曼、科威特、吉达甚至红海方向的柜子，同样要在杰贝阿里提交舱单。中转柜的舱单数据来源更分散（头程船司+二程船司），漏报概率更高，建议本周把所有经 UAE 中转的在途和待发订单过一遍。 第三，延误成本明确化。杰贝阿里的堆存费约 $30-60/天/柜，新规卡关 2-3 天，一个 40HQ 多出 $60-180 的堆存费，加上目的港清关延误带来的客户索赔风险。这些费用按行业惯例由发货方承担，发货人不知道新规，最后扯皮的是货代。 操作节奏：今天起，所有 UAE 目的港及经杰贝阿里中转的订单，订舱时同步收集完整舱单要素；给主要发货客户发一条书面通知，列明新规要求的单证清单和截单时间；与Maersk订舱代理确认新规的执行宽限期——部分口岸新政实施初期有 2-4 周的缓冲期，确认清楚再承诺客户。 一句话总结：这不是费用问题，是合规问题——舱单数据不齐，柜子上不了船，9月23日起新规已生效，不要拿在途货去试。
